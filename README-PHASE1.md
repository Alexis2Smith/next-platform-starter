# Ascend AI NOW Digital Headquarters — Phase 1

This branch replaces the default Netlify starter landing page with the Phase 1 Executive Command Center shell.

## Phase 1 scope
- Branded Digital Headquarters shell
- Executive identity header
- Command Center navigation architecture
- Executive metric cards
- Decision Queue
- AI POWER GAP™ governance pulse
- Governance workstream progress
- Executive agenda
- Responsive desktop/tablet/mobile layouts

## Official brand asset
The interface is wired to use the approved Ascend AI NOW logo at:

`public/images/ascend-ai-now-logo.png`

Do not substitute a generic AI mark. The approved logo asset should be added before production merge if it is not already present.

## Deployment workflow
1. Build and review this branch.
2. Open a pull request against `main`.
3. Review the Netlify Deploy Preview.
4. Validate responsive behavior, accessibility, performance, and official branding.
5. Merge only after approval.

The dashboard data in Phase 1 is intentionally presentation/demo data. Phase 2 will replace it with authenticated workspaces, persisted governance records, and operational workflows.
